# Setup a Next.js Project

This guide walks you through creating and running a **Next.js** project from scratch.

## Prerequisites

- [Node.js](https://nodejs.org/en/download/) version **18.17** or above
- Any package manager of your choice: `npm`, `pnpm`, `yarn`, or `bun`

## Create a new project

Use the official `create-next-app` tool:

```bash
npx create-next-app@latest my-next-app
```

You will be prompted for a few options:

- **TypeScript**: Yes/No
- **ESLint**: Yes/No
- **Tailwind CSS**: Yes/No
- **`src/` directory**: Yes/No
- **App Router**: Yes/No (uses the newer App Router)
- **Turbopack**: Yes/No (for faster dev builds)

The tool installs all required dependencies automatically.

## Run the development server

```bash
cd my-next-app
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. The page
**auto-reloads** whenever you save changes to your files.

## Project structure

After scaffolding, your project looks like this:

```
my-next-app/
├── app/            # App Router pages & layouts
│   ├── layout.tsx
│   ├── page.tsx
│   └── globals.css
├── public/         # Static assets
├── package.json
└── next.config.ts
```

### Editing your first page

Open `app/page.tsx` and change the content — the site reloads instantly.

## Build for production

```bash
npm run build
npm run start
```

`npm run build` creates an optimized production bundle, and `npm run start`
serves it locally for you to preview before deploying.
